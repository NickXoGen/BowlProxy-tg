# 🚀 BowlProxy tg (by Dr.Bowling)

**BowlProxy tg** — это мой личный проект, сделанный **чисто по фану**.

Это локальный прокси-сервер для Telegram Desktop на Python с графическим интерфейсом. Его главная задача — обходить жесткие блокировки провайдеров (ТСПУ/DPI), перенаправляя MTProto-трафик через WebSocket (wss://) на серверы Cloudflare и маскируя его под обычный безобидный HTTPS.

### 📖 История создания (Честно)
Этот проект родился через боль, страдания и бесконечные ошибки ИИ **DeepSeek**. Я не профессиональный программист, я просто хотел, чтобы Телега работала без танцев с бубном. Мы с DeepSeek сутками фиксили расшифровку AES-CTR, ловили ошибки DLL при сборке PyInstaller и переписывали `RawWebSocket`.

Огромное спасибо **[Flowseal](https://github.com/Flowseal/tg-ws-proxy)** за его невероятный реверс-инжиниринг протокола. Без его исходников и списков доменов Cloudflare, я бы (да и DeepSeek тоже) никогда в жизни не собрал бы этот прокси.

## ✨ Что тут есть (Особенности)

*   🖥 **Графический интерфейс (GUI)**: Удобное темное окно на Tkinter. Никаких черных консолей, командных строк и Docker. Нажал кнопку — работает.
*   🛡 **Обход ТСПУ/DPI**: Встроенный список зашифрованных Cloudflare-доменов. Провайдер видит соединение с `kws2.virkgj.co.uk`, а не с Telegram.
*   📊 **Прозрачность**: Встроенный журнал показывает всё в реальном времени (какой DC парсится, какой домен используется, передаются ли медиафайлы).
*   ⚙️ **Удобная настройка**: В интерфейсе можно выбрать тип прокси (SOCKS5 или MTProto), и по кнопке программа сгенерирует и отправит нужную ссылку прямо в Telegram.
*   📦 **Сборка в один EXE**: Использован `pycryptodome` вместо `cryptography`, чтобы сборка через PyInstaller проходила без ошибок DLL на Windows.

## 🛠 Как это работает (Под капотом)

Вся магия — в перехвате и перешифровке пакетов:
1. **Разбор Obfuscated2**: Читаем 64-байтовый заголовок от Telegram, перебирая `raw/sha256` ключи и `BE/LE` счётчики, чтобы точно определить `DC ID`.
2. **Генерация Relay Init**: Вместо клиентского заголовка прокси генерирует свой собственный, который сервер Telegram принимает без ошибок.
3. **Полная перешифровка (Re-encryption)**: Трафик от клиента расшифровывается его ключами и заново шифруется ключами `relay_init` перед отправкой в WebSocket.
4. **Собственный RawWebSocket**: Стандартная библиотека `websockets` добавляет лишние заголовки, которые рвут соединение. Написан свой класс на `asyncio` с точным соблюдением протокола.
5. **MsgSplitter**: Нарезка потока на точные куски (по длине пакета), так как Telegram ожидает ровно один MTProto-пакет в одном WebSocket-сообщении.
6. **TCP_NODELAY**: Отключен алгоритм Нейгла, чтобы пакеты уходили мгновенно (иначе Телега отваливается по таймауту).

## 🚀 Установка и запуск

### Для обычных пользователей (Windows)
1. Перейди в раздел **[Releases](../../releases)**.
2. Скачай готовый файл `BowlProxy_tg.exe`.
3. Запусти его (если Windows SmartScreen ругается, нажми «Подробнее» -> «Выполнить в любом случае», это нормально для неподписанных EXE).
4. В программе нажми **«▶ Запустить сервер»**.
5. Нажми **«🔧 Настроить прокси в Telegram»** — Телеграм спросит разрешение на добавление прокси, соглашайся.
6. Готово!
