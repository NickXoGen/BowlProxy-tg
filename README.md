# 🚀 BowlProxy tg (by Dr.Bowling)

**BowlProxy tg** — это мощный, но невероятно удобный локальный прокси-сервер для Telegram Desktop на Python.

Его главная задача — **обходить жесткие блокировки провайдеров (ТСПУ/DPI)**. Программа перенаправляет MTProto-трафик через WebSocket (wss://) на серверы Cloudflare, маскируя его под обычный безобидный HTTPS-трафик.

Проект вдохновлен легендарным `Flowseal/tg-ws-proxy`, но полностью переписан под нужды **обычных пользователей Windows**, которым нужна кнопка «Запустить», а не консольные команды.

---

## ✨ Главные преимущества (Почему мы лучше?)

Мы сделали то, чего так не хватало оригинальному консольному проекту:

*   🖥 **Графический интерфейс (GUI)**: Удобное темное окно на Tkinter. Никаких черных консолей и команд Docker.
*   🤖 **Полная автоматизация**: Нажимаете одну кнопку — программа сама находит `Telegram.exe`, запускает его и применяет настройки прокси через `tg://socks` или `tg://proxy` диплинки.
*   📊 **Визуализация и прозрачность**: Встроенный журнал в реальном времени показывает, какой DC (дата-центр) парсится, какой домен Cloudflare используется и как передаются медиафайлы.
*   📦 **Сборка в один EXE**: Используется `pycryptodome` вместо проблемной `cryptography`, что позволяет собрать портативный `BowlProxy_tg.exe` без ошибок DLL на Windows.
*   🛡 **Готовность к ТСПУ**: Встроенный список зашифрованных Cloudflare-доменов (от Flowseal) и умный fallback (резервные варианты).
*   ⚙️ **Выбор типа прокси**: Прямо в интерфейсе можно выбрать тип прокси для Telegram (SOCKS5 или MTProto), и приложение сгенерирует правильную ссылку.

## 🛠 Как это работает (Архитектура)

Вся магия происходит на уровне перехвата и перешифровки пакетов:

1. **Разбор Obfuscated2**: Программа читает 64-байтовый заголовок от Telegram, перебирая `raw/sha256` ключи и `BE/LE` счётчики, чтобы точно определить `DC ID` и тип транспорта (Abridged, Intermediate, Padded).
2. **Генерация Relay Init**: Вместо клиентского заголовка прокси генерирует свой собственный `relay_init` (с правильным сдвигом ключей и шифрованием хвоста), который WebSocket-сервер Telegram принимает без ошибок.
3. **Полная перешифровка (Re-encryption)**: Весь трафик от клиента расшифровывается его ключами и заново шифруется ключами `relay_init` перед отправкой в WebSocket. Обратный процесс происходит для трафика от Telegram.
4. **Собственный RawWebSocket**: Стандартная библиотека `websockets` не подходит — она добавляет лишние заголовки и PING-фреймы, которые рвут соединение. Был написан свой класс на `asyncio` с точным соблюдением протокола (`Sec-WebSocket-Protocol: binary`).
5. **MsgSplitter**: Telegram ожидает, что каждое WebSocket-сообщение содержит ровно один MTProto-пакет. Встроенный сплиттер нарезает зашифрованный поток на точные куски по длине пакета.
6. **Обход блокировок**: Провайдер видит соединение с `kws2.virkgj.co.uk` (или другим доменом Cloudflare), а не с `telegram.org`.
7. **Фикс медиа**: Для файлов и картинок Telegram использует отрицательные DC ID (например, DC-2). Программа поддерживает их и использует специальные домены `kws2-1.*` для медиа-трафика.
8. **TCP_NODELAY**: Установлен флаг отключения алгоритма Нейгла. Пакеты уходят мгновенно, что спасает от ошибки таймаута `1006`.

## 🚀 Установка и запуск

### Для обычных пользователей (Windows)
1. Перейди в раздел **[Releases](../../releases)**.
2. Скачай готовый файл `BowlProxy_tg.exe`.
3. Запусти его (если Windows ругается, нажми «Подробнее» -> «Выполнить в любом случае»).
4. Нажми зеленую кнопку **«▶ Запустить и открыть Telegram»**. Всё!

### Для разработчиков (Запуск из исходников)
Убедитесь, что у вас установлен **Python 3.12+** (важно: на 3.15 могут быть проблемы с PyInstaller).
